EzStuff

EzStuff is a personal tool with one user, its owner. It is not offered to anyone else.

Once a day it builds a SQLite file of public data about the quiz game "What? Where? When?": the question packs published on gotquestions.online and the tournament results published on rating.chgk.info. It uploads that file to its owner's Google Drive, replacing the previous day's copy, so the owner's teammates can download it.

It asks Google for one permission, drive.file. With it, EzStuff can see and change only the files it created itself. It cannot see, open or change any other file in the owner's Drive.
